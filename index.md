# Assignment 1.2 — Development Environment Setup

## Steps Completed

1. Installed Visual Studio Code.
2. Installed the LTS version of Node.js.
3. Installed the Live Server and Prettier extensions in VS Code.
4. Created a folder named `web-development-practice`.
5. Created `index.html`, `style.css`, and `script.js` inside the folder.
6. Ran `index.html` in the browser using Live Server.
7. Verified the installation by running `node -v` and `npm -v` in the terminal.

## Explanation

Visual Studio Code is the editor I used to write the project files. Node.js lets JavaScript run outside the browser, and npm is the package manager included with Node.js. I installed the LTS version because it is a stable release. The Live Server extension opens the HTML file in a browser and refreshes the page when I save changes. Prettier formats code to keep it consistent and readable.

The `web-development-practice` folder contains three basic webpage files: `index.html` for the structure, `style.css` for the design, and `script.js` for the behavior. Running `node -v` and `npm -v` in the terminal displays the installed version numbers and confirms that Node.js and npm are available.
